## Что ещё требует внимания

1. В афише остаются **11 площадок с приблизительными координатами по городу**.
   Сборка честно сообщает об этом. Для точных меток нужны проверенные адреса
   конкретных филиалов; это отдельные данные, не те две ошибки карты собраний.
2. Исходный пост о Марунума называет город «Асакуса». Официальный адрес —
   **Асака, Сайтама**. В справочнике и координатах указан правильный город;
   ключ и название из Telegram сохранены для стабильности ссылок. Текст
   исходного поста следует исправить при следующем редактировании контента.
3. `generate_map.py`, `site_common.py`, `sitebuild/afisha.py` и `posts.py`
   остаются крупными. Разделение встроенного JavaScript и Python на модули
   упростит дальнейшую поддержку, но требует отдельного изменения с тестами.
4. Проверки и публикация Pages независимы. Для обязательного зелёного CI до
   публикации нужна отдельная настройка защищённой ветки/единого deploy workflow.
5. В репозитории открыт [Dependabot PR #1](https://github.com/DenchesT/Site-Oldpictureart/pull/1)
   с переходом Pillow 12.3 → 13.0. Он не включён и не слит в рамках аудита.
6. Разовые `apply_*.py`/`fix_*.py` накопились в корне. Их можно вынести в архив
   инструментов вместе с зависимыми тестами; удалять по маске сейчас нельзя.
