# Проверки

Браузерные проверки сайта: Playwright открывает собранные страницы
в Chromium и смотрит, что всё на месте и работает — кнопки, фильтры,
тема, карта, лупа, скачивание, разметка, вёрстка на узких экранах.

## Что нужно один раз

```bash
npm ci                                       # Playwright той версии, что в package-lock.json
npx playwright install chromium
python -m pip install -r requirements-dev.txt   # модули сборки + moto и pyflakes для проверок
```

Leaflet и группировка меток лежат на самом сайте (`docs/vendor/`),
поэтому карта в проверках работает без интернета, прямо из `docs/`.
Проверкам, которым нужно перехватывать запросы к этим файлам (например,
«библиотека группировки не загрузилась»), `tests/_static.js` поднимает
маленький веб-сервер на `127.0.0.1` — с `file://` Playwright запросы не
перехватывает.

Те же проверки идут на GitHub при каждом push
(`.github/workflows/tests.yml`) — результат на вкладке Actions.

## Запуск

```bash
python rebuild_pages.py     # сначала собрать сайт
node tests/run.js           # прогнать всё
node tests/test_lupa.js     # или что-то одно
```

Проверки читают готовые страницы из `docs/`, поэтому запускать их
нужно **после** сборки — иначе они посмотрят на прошлую версию.

## Что где

|---|---|
| `test_ui.js` | кнопки, фильтры, поиск, тема, клавиатура |
| `test_batch.js` | все типы страниц целиком, ссылки, якоря |
| `test_design.js` | оформление «Каталог», миниатюры, контраст, ширины экрана |
| `test_layout.js` | вёрстка служебных страниц: 404 (подвал под сообщением), шапка указателя, одинаковые шапки карты, хронологии и квиза, график десятилетий на телефоне, длинный хэштег не раздвигает страницу, происхождение нумерованным списком |
| `test_polish.py` | типографика текста из канала (тире, «ёлочки»), миниатюры не крупнее 600px и уменьшение прежних, нет одинаковых заголовков вкладки |
| `test_pages.js` | страницы художников, указатель, статистика, «рядом в собрании» |
| `test_lupa.js` | полноэкранный просмотр, скачивание оригинала, панель и жесты на телефоне |
| `test_museums.js` | страница музеев и карта |
| `test_markers.js` | метки-этикетки и группировка скоплений |
| `test_addresses.js` | адреса музеев и поиск по ним |
| `test_mapfail.js` | карта не пустеет, если сохранён «Яндекс» или не загрузилась библиотека; логотип Яндекса в углу |
| `test_brand.js` | знак сайта, значки для вкладки и телефона, подвал |
| `test_visits.js` | посещения: переключатели, заголовки, сетка снимков, места на карте, лупа |
| `test_refresh.py` | правка старого поста: `--refresh`, перечитывание базы, переезд страницы |
| `test_mapcheck.py` | метки на карте: выбор находки, разбор полётов `--check`, ссылки на сайты |
| `test_links.py` | ссылки из постов: разметка Telegram, заголовок похода, «Источники», дочитывание |
| `test_hires_store.py` | оригиналы в хранилище: выгрузка, заголовки, перенос в архив, ссылки со страниц |
| `test_run_status.js` | «Идёт до …»: каждая граница срока выставки при подставленной дате |
| `test_museum_pages.js` | страницы музеев: ссылки на них отовсюду, разметка, мини-карта, телефон |
| `test_museum_data.py` | срок выставки, адрес страницы музея, разметка для поисковиков, метки слежения |
| `test_check_links.py` | проверка внешних ссылок: сбор, отчёт, подсказки |
| `test_calendar.py` | блок «Идёт сейчас»; календаря `.ics` больше нет, прежний файл убирается |
| `test_afisha.py` | афиша: проверка записей, кто идёт и кто скоро, страница и фильтры, «На сайте: …» (фамилии в падежах), «Был — снимки» и обратная ссылка, разметка ExhibitionEvent, еженедельная проверка ссылок, блок главной, подсказки сборки, сам `afisha.json` |

| `test_artist_info.py` | годы жизни и Википедия у художников: поиск, кэш, ручные поправки, без сети |

Страница работы, на которой идут проверки, выбирается из
`posts_meta.json`, а не задана жёстко: конкретный пост могут удалить.
`test_visits.js` устроен так же и, если `visits_meta.json` нет, ничего
не проверяет: раздел посещений в такой сборке и не создаётся.

## Если что-то падает

числами. Обычная причина — забыли пересобрать сайт после правки.
