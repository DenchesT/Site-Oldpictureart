## Как получить **готовые** два обновлённых JSON-файла

**Сохраняйте пакет отдельно от папки проекта** и не переносите `proposal.json` вместо `afisha.json`.

1. Распакуйте архив, например в `D:\\Code\\opa_update_2026_11_10`.
2. Для просмотра изменений без записи запустите из распакованной папки:

```powershell
python apply_local_update.py --dir "D:\Code\oldpictureart_site"
```

3. Для создания обоих готовых JSON и полной 126-строчной таблицы аудита в **новом каталоге** (локальная копия не затрагивается):

```powershell
python apply_local_update.py --dir "D:\Code\oldpictureart_site" --export "D:\Code\opa_review_result"
```

В каталоге `opa_review_result` появятся **`afisha.json`, `afisha_archive.json`, `source_audit_126.csv`, `apply_summary.json`**. Переносить файлы в исходный проект можно вручную после проверки.

4. **Только если вы сами решите применить изменения локально**, можно запустить:

```powershell
python apply_local_update.py --dir "D:\Code\oldpictureart_site" --apply
```

Перед записью будут созданы `afisha.json.bak-2026-11-10` и `afisha_archive.json.bak-2026-11-10` (повторное применение не перезапишет эти резервные файлы).

По умолчанию три завершившиеся по датам выставки без повторного официального подтверждения **не архивируются**: «Сказка рядом», «Николай Хохряков. Поэзия природы», «Окрестности Санкт-Петербурга в гравюрах и литографиях XIX века». Для их включения только после самостоятельной проверки можно указать `--include-unconfirmed`.
