# Old Picture Art — локальное предложение от 02.11.2026

**GitHub не изменялся.** Архив предназначен для ручной проверки и локального применения к `DenchesT/Site-Oldpictureart` (`main` на момент проверки).

## Содержимое

- `archive_changes.json` — 3 полные записи для переноса и метаданные исходного состояния; 1 неподтверждённый кандидат вынесен отдельно.
- `afisha_archive.json` — готовая версия архива **для исходного состояния, в котором архив пуст**. Не заменяйте этим файлом более новый архив, содержащий другие выставки!
- `apply_local_update.py` — безопасный локальный инструмент: без флага `--apply` он ничего не записывает, с флагом переносит записи из текущего `afisha.json` в актуальный `afisha_archive.json`, не трогая `sources`, делает резервные копии.
- `README.md` — эта инструкция.

## Как применить без риска потерять новые записи

1. Распакуйте ZIP в **отдельную временную папку**, не поверх проекта.
2. Проверьте предложение в `archive_changes.json` и официальные страницы ниже.
3. На компьютере с Python 3 запустите просмотр изменений:

   `python apply_local_update.py --dir "ПУТЬ_К_ПРОЕКТУ"`

4. При согласии явно выполните **только локальное** обновление:

   `python apply_local_update.py --dir "ПУТЬ_К_ПРОЕКТУ" --apply`

5. Скрипт создаёт резервные копии `afisha.json.bak-2026-11-02` и `afisha_archive.json.bak-2026-11-02`. Никаких commit, push, pull request, публикаций или сетевых запросов он не выполняет.

Ожидаемые числа для исходного `main`: было 191 текущая выставка и 0 архивных; станет 188 текущих и 3 архивных. Источников `sources` останется 126.
