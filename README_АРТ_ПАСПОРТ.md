# Old Picture Art — личный арт-паспорт (08.11.2026)

**Исходник:** `DenchesT/Site-Oldpictureart`, ветка `main`. Пакет предназначен для локального применения. **Никаких commit/push и запросов в GitHub скрипты не делают.**

## Что было уже на сайте

- Лайки картин `likes` (гость — локально; вошедший — через существующую Yandex Cloud/YDB).
- Избранные выставки `afishaFavorites` (действующая синхронизация между устройствами).
- Отдельный дневник `visits.html` — посещения **автора канала**, не посетителя сайта.
- Авторизация Яндекс ID и VK ID, статическая генерация Python в `docs/`.

## Что добавлено

1. `passport.html` — отдельный личный раздел в стиле сайта: статистика по вашим действиям, любимые картины, художники, музеи, оригиналы, тематические коллекции, избранные выставки.
2. Кнопки «Любимый художник» на страницах художников, «Я был в этом музее» на страницах музеев, «Видел оригинал» и «В мою коллекцию» на страницах картин.
3. Поиск среди художников, музеев и работ; коллекции с переименованием, добавлением/удалением картин и удалением коллекции.
4. Экспорт/импорт JSON (личные данные + лайки, **без токенов входа**) для резервной копии и переноса на другой браузер.
5. Личный паспорт **не подменяет** дневник `#галерея/#выставка` — авторские посещения не присваиваются посетителю.
6. Новый паспорт доступен с главной через ссылку меню «Мой арт-паспорт». На странице «Посещения» также есть ссылка.

## Какие данные синхронизируются

**В облако, как прежде:** понравившиеся картины и выставки, при авторизации через действующую Yandex Cloud Function. Код существующей функции и структура YDB **не меняются**.

**Только в браузере:** личные художники, музеи, отмеченные оригиналы и названия/состав собственных коллекций. Данные локально разделяются по аккаунтам (идентификатор из действующей авторизации) и гостевому режиму. Это сознательное ограничение: не записываем личную историю посещений в общую таблицу лайков и не меняем облако без миграции. Для другого устройства экспортируйте JSON и импортируйте его там. Импорт **заменяет локальные данные паспорта** выбранного аккаунта; лайки добавляет. Файл не содержит токенов и секретов, но может раскрывать ваши вкусы/маршруты — храните его приватно.

## Как установить (PowerShell)

**Перед установкой** проверьте, что незакоммиченные изменения сохранены/понятны (`git status --short`). Распакуйте **содержимое ZIP прямо в корень** `D:\Code\oldpictureart_site`, сохранив подкаталоги `docs/`, `sitebuild/`, `tests/`. Существующие исходные файлы на этом шаге ещё не заменяются.

```powershell
cd D:\Code\oldpictureart_site
python apply_art_passport.py --check
python apply_art_passport.py --apply
python -m unittest discover -s tests -p test_passport.py
node tests/test_passport_actions.js
python rebuild_pages.py --offline
```

Откройте `docs/passport.html` (лучше через локальный HTTP-сервер, потому что авторизация на `file://` не работает). Проверьте кнопки на нескольких реальных страницах, тёмную тему и мобильный экран.

Изменения файлов генератора создаются инсталлятором в вашей рабочей копии. Резервные копии лежат в соседней папке `oldpictureart_site_backup_art_passport_YYYYMMDD_HHMMSS`, не внутри репозитория. При неподходящей версии исходника `--check` откажется применять изменения; **не запускайте установку через силу**.

После пересборки выполнить:

```powershell
git status --short
python -m compileall -q sitebuild
npm test
```

При удовлетворительных результатах вы сами выбираете, что коммитить и отправлять. **Не запускайте `python build_site.py` для локальной проверки** — без `--no-push` эта команда может автоматически публиковать изменения; для проверки достаточно `rebuild_pages.py --offline`.

## Файлы, которые изменит установщик

- `build_site.py` — пересборка паспорта после получения новых публикаций.
- `rebuild_pages.py` — офлайн-пересборка паспорта из текущей базы.
- `sitebuild/posts.py` — ссылка в меню и кнопки на страницах картин.
- `sitebuild/artists.py`, `sitebuild/museums.py` — кнопки на страницах художников и музеев.
- `sitebuild/visits.py` — ссылка на собственный паспорт рядом с дневником автора.

## Новые файлы

- `sitebuild/passport.py` — генератор.
- `docs/passport.js`, `docs/passport-actions.js`, `docs/passport.css` — интерактивность и оформление.
- `tests/test_passport.py`, `tests/test_passport_actions.js` — регрессии.
- `apply_art_passport.py`, `README_АРТ_ПАСПОРТ.md` — установка.

`docs/passport.html`, `docs/index.html` и обновлённые HTML-страницы появятся/изменятся при локальном `python rebuild_pages.py --offline`. Репозиторий/канал Telegram скрипты не трогают. Пользовательское состояние хранится в `localStorage` и не должно попадать в Git.

## Проверка после сборки

1. Поставьте лайк картине, откройте паспорт — картина есть в «Обзоре».
2. Добавьте художника и музей; обновите страницу — отметки сохранились.
3. На странице конкретной картины нажмите «Видел оригинал», проверьте раздел «Оригиналы».
4. Создайте коллекцию и добавьте картину, обновите страницу, затем удалите её из коллекции.
5. Выгрузите JSON и импортируйте обратно; проверьте статистику.
6. Войдите под другим аккаунтом/выйдите — личные отметки другого аккаунта не отображаются.
7. Убедитесь, что дневник `visits.html` остался неизменным по смыслу.
8. На телефоне проверьте горизонтальную навигацию и открытие окна добавления картины.
