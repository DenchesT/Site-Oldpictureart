# Полный первичный проход по источникам Old Picture Art — 10 ноября 2026 года

## Метод и достоверность

**Репозиторий только читался.** Основной файл: `afisha.json` из `main` (191 выставка, 126 источников), архив `afisha_archive.json` (3 выставки). Снимок закреплён SHA Git blob в `proposal.json`. В `sources` есть 67 записей с `url` или `site` и 59 без обоих полей.

В рамках прохода предпринято открытие всех **67 известных URL** и **поисковая попытка для каждого из 59 музеев без URL**. Разные записи могут делить один URL: `#22` и `#59` относятся к одному сайту. **Это полный охват попыток, но НЕ полный подтверждённый обход афиш**. Получить текст разделов выставок и проверить даты всех музеев не удалось. 16 записей в источниках имеют явно зафиксированные сбои открытия/чтения; ещё 59 не имели исходного URL. Для 12 из этих 59 найдены официальные страницы, но полноценная программа выставок проверена не для каждого. У остальных 47 по-прежнему нет подтверждённого официального ресурса (2 ссылки-кандидата отдельно, 45 без пригодной подтверждённой ссылки). Не делается вывод «новых больше нет».

## Как пользоваться результатом

`proposal.json` является проверяемым **набором предлагаемых изменений**, а не заменой `afisha.json`. Программа `apply_local_update.py` собирает оба полноценных JSON **из актуальных локальных оригиналов**, без потери других записей. Также может экспортировать подробную таблицу **каждого из 126** источников с именем, URL, статусом, исправлением и причиной. Используйте `README.md`.

**Никаких GitHub-коммитов, push, веток, PR и публикации не выполнялось.**
