# Old Picture Art — один уровень фильтров мобильной афиши

Основа: актуальные генераторы `sitebuild/afisha.py` и `docs/style.css` из
`DenchesT/Site-Oldpictureart`, проверено на ветке `main` 31.10.2026.

## Что изменится

**На телефоне (ширина до 700 px):**
- «Сейчас и скоро / Идут / Скоро / Архив / Избранное / Все периоды» остаются на виду.
- Единый поиск по выставкам, художникам, музеям и городам остаётся на виду.
- Кнопка **«Фильтры»** раскрывает сразу весь набор параметров: город/страну,
  музей, эпоху, дату закрытия или открытия, год архива, «Рядом со мной» и сброс.
- Вложенный заголовок **«Дополнительные фильтры»** больше не отображается.
- Сортировка остаётся над результатами.
- Данные, существующее избранное и весь текст описания не меняются.

**На компьютере (ширина больше 700 px):** прежнее раскрытие «Дополнительных
фильтров» сохраняется. При повороте телефона или изменении ширины страницы
состояние десктопного блока корректно восстанавливается.

## Установка — без дополнительных папок

Распакуйте **все файлы ZIP** непосредственно в корневую папку проекта
`D:\Code\oldpictureart_site`.

Откройте PowerShell в этой папке:

```powershell
python apply_single_mobile_filters.py --check
python test_single_mobile_filters.py
python apply_single_mobile_filters.py --apply
python rebuild_pages.py --offline
python tests/test_afisha.py
node tests/test_afisha.js
```

Первый запуск (`--check`) **не изменяет ничего**. `--apply` вносит изменения
только в `sitebuild/afisha.py` и `docs/style.css`, а перед записью создаёт
резервные копии `*.before-single-mobile-filters-*.bak` рядом с файлами.
Повторный запуск ничего не дублирует.

После пересборки обновите страницу афиши в браузере. Если браузер показывает
старые стили, обновите страницу без кеша или перезапустите браузер.

## Проверки и ограничения

- Проверены синтаксис Python и вставляемого JavaScript, целостность якорей
  текущих исходников, повторное применение и отказ при несовместимой версии.
- Мобильное открытие/закрытие и переключение между мобильным/десктопным
  режимами проверены в локальном Chromium на тестовой HTML-странице.
- Полный браузерный прогон именно вашего локального проекта должен быть
  выполнен командами выше (зависит от всех локальных файлов, данных и
  зависимостей).
- Никаких изменений в GitHub этот пакет **не отправляет**.

Если `--check` сообщает, что версия кода отличается, не применяйте исправление
силой — пришлите вывод проверки, чтобы не повредить другие доработки.

`test_single_mobile_filters.py` использует только стандартную библиотеку
для базовых проверок; если доступен Python Playwright с Chromium, дополнительно
проверяет поведение в реальном браузере. Тест не меняет файлы проекта.
