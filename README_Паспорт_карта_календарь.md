# Old Picture Art — исправления карты, календаря и кнопок арт-паспорта (v3.2)

**Дата:** 09.11.2026. **Ветка проекта:** `main`. **Публикацию/commit/push выполняет владелец сайта.**

## Исправления

1. **Карта:** исправлен явно отключённый в `docs/passport.js` параметр Leaflet `scrollWheelZoom:false` → `true`. Колёсико мыши меняет масштаб, как на основной карте музеев. Остались прежние механизмы `OPA_MAP.attach` (подложки/тёмная тема), кластеризация и разворот на весь экран. На смартфонах масштабируется обычным жестом двумя пальцами.
2. **Главная арт-паспорта:** четыре действия «+ Посещение», «+ Увиденный оригинал», «+ Коллекция», «Моя карта» теперь в равномерной сетке с одинаковой шириной и высотой. На компьютере четыре колонки; на телефоне — две колонки по две кнопки, в том числе на узких экранах 320px. Убраны разные внешние отступы у кнопки с акцентной заливкой.
3. **Календарь:** собственный календарь сайта больше не обрезается внутри модального окна: он раздвигает форму, а модальное окно прокручивается внутри себя. При открытии календаря закрывается экранная клавиатура, и диалог прокручивается так, чтобы календарь был виден. На экранах с малой высотой пользователь может прокрутить его целиком. На ПК календарь компактный, на телефоне — по ширине формы. Ручной ввод даты ДД.ММ.ГГГГ сохранён.
4. **Кэш:** после `rebuild_pages.py --offline` обновляются URL `passport.js` и `passport.css` с параметром версии, чтобы пользователи не видели старый код из браузерного кэша.
5. Включены ранее подготовленные исправления падений CI: прямые импорты в `test_passport.py`/`test_passport_sync_installer.py`, экспорт имён в `passport_ids.py` и удалённый неиспользуемый импорт из `test_passport_upgrade_v3.py`.

**Без изменений:** Cloud Function, схема YDB, хранимые отметки пользователей, механизмы синхронизации и входа. Сохранять что-либо в облаке или менять `cloud/auth/index.py` для этого обновления **не нужно**.

## Установка

Архив содержит файлы в тех же относительных путях, что в репозитории, без дополнительной вложенной папки. **Используйте его после установки арт-паспорта v3.** Перед распаковкой сохраните локальные изменения. Если после v3 вы вручную редактировали указанные файлы, сначала сравните их с версией из архива, чтобы не затереть свои правки.

1. Распакуйте файлы в корень `D:\Code\oldpictureart_site` (с сохранением папок `docs`, `sitebuild`, `tests`).
2. В PowerShell запустите:

```powershell
cd D:\Code\oldpictureart_site
python tests/test_passport_map_ui.py
node tests/test_passport_actions.js
node tests/test_passport_cloud.js
node tests/test_passport_v3_sync.js
python rebuild_pages.py --offline
git diff --check
git status --short
```

3. Локально откройте `docs/passport.html` и проверьте вкладку «Карта», кнопки в «Обзор» и выбор даты в «Оригиналы». При публикации изменения попадут на `https://oldpictureart.ru/passport.html`.
4. Просмотрите `git diff` и отправьте файлы самостоятельно.
