# Old Picture Art — первая фотография в карточках посещений

Исходник проверен по GitHub `DenchesT/Site-Oldpictureart`, `main`, 08.11.2026.

## Что меняется

- В разделе «Посещения», в обеих вкладках «Выставки» и «Постоянные экспозиции», обложкой карточки становится **первая фотография Telegram-поста**.
- На страницах музеев, где выводятся карточки посещений, будет тот же первый кадр.
- Миниатюра `thumbs[0]` используется при наличии, иначе исходный `images[0]`.
- Никакие фотографии не удаляются; порядок снимков внутри самих публикаций не меняется.
- Навигация, фильтры, избранное и остальные страницы не затрагиваются непосредственно изменением кода.

## Как применить в PowerShell

1. Распакуйте **содержимое ZIP в корень вашего клона** `D:\Code\oldpictureart_site`, рядом с `sitebuild/` и `rebuild_pages.py`.
2. Сохраните свои текущие изменения; проверьте `git status --short`.
3. В PowerShell выполните:

```powershell
cd D:\Code\oldpictureart_site
python apply_visit_first_photo.py --check
python apply_visit_first_photo.py --apply
python test_visit_first_photo.py
python rebuild_pages.py --offline
python -m unittest discover -s tests
# затем проверьте изменения
 git status --short
 git diff -- sitebuild/visits.py docs/visits.html
```

`--check` ничего не изменяет. `--apply` редактирует **только** `sitebuild/visits.py`, прежде сохранив резервную копию вне репозитория в папке `OldPictureArt_visit_cover_backups` на уровень выше проекта. Выполнить `--apply` повторно безопасно.

`rebuild_pages.py --offline` пересоздаёт с учётом текущих JSON **все нужные HTML-файлы**, включая `docs/visits.html` и музейные страницы. Для быстрой проверки откройте `docs/visits.html` и проверьте несколько карточек в обоих режимах просмотра.

Скрипт ничего не отправляет в GitHub. Когда всё проверено, самостоятельно добавьте и закоммитьте именно нужные изменения; не публикуйте `.env`, сессии Telegram и резервные копии. С учётом прежних локальных изменений проверяйте `git diff` перед отправкой.

## Если версия кода другая

При несовпадении сигнатур скрипт отменяет изменения. Не редактируйте файлы вручную без сравнения с новой версией генератора.
