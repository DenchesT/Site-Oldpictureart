# Old Picture Art — мобильное меню и избранные выставки

Подготовлено по GitHub `DenchesT/Site-Oldpictureart`, ветка `main`, коммит `d287a40f` (31 октября 2026 года). **Действующий дизайн не меняется.** Это пакет-установщик для генераторов, а не копия целого проекта.

## Изменения

1. **Телефоны (до 900 px):** на странице галереи над картинами остаётся кнопка **«Меню»**. Сортировка, переключатель «Подробный список / Карточки», счётчик найденных картин, сброс и выбранные фильтры оказываются внутри выдвижного меню, сразу под поиском. На компьютерах всё остаётся на прежних местах. При повороте телефона элементы возвращаются на нужную позицию без клонирования.
2. **Подпись поиска:** вместо «Поиск по названию, автору и музею · клавиша /» — **«Поиск по названию, художнику или музею»**. Мгновенная фильтрация и клавиша `/` продолжают работать.
3. **Избранные выставки:** ☆ на странице афиши сохраняются локально, а **при авторизации через Яндекс ID/VK ID — также в существующем Yandex Cloud/YDB**. Отметки синхронизируются между устройствами, снимаются, переживают обновление страницы; изменения без сети откладываются до повторной синхронизации. Для выставок используются идентификаторы `exh_` + хеш, поэтому они не смешиваются с номерами картин и помещаются в ограничение сервера 40 символов. Создавать новую таблицу YDB не нужно.
4. **Раздел «Избранное»** в боковом меню разделён на **«Картины»** и **«Выставки»** с общим счётчиком, названиями и музеями и ссылкой на всю подборку в афише. Архивные выставки остаются видимы в избранном. На странице афиши добавляется работающая кнопка «Войти/Профиль», использующая существующий механизм входа.
5. **Отступы мобильных карточек:** между разделителями и текстом больше воздуха. После возврата назад фокусная рамка больше не касается текста. Каталожный номер `№037` не переносится на две строки.
6. **Исправляется публикация JS:** `docs/opa-ui.js` синхронизируется с корневым `opa-ui.js`. В текущем репозитории эти файлы различаются — без этого новая логика меню не попала бы на опубликованный сайт.

## Установка в PowerShell

Сначала сохраните изменения в вашей рабочей копии (`git status`) и проверьте, что проект соответствует указанному коммиту. Распакуйте **только четыре файла из ZIP** в корень `D:\Code\oldpictureart_site`:

- `apply_mobile_favorites.py`
- `test_mobile_favorites.py`
- `test_mobile_cloud.js`
- `README_MOBILE_FAVORITES.md` (эта инструкция)

Затем выполните:

```powershell
cd D:\Code\oldpictureart_site
python apply_mobile_favorites.py --check
python apply_mobile_favorites.py --apply
python test_mobile_favorites.py
python -m compileall -q sitebuild cloud
python rebuild_pages.py --offline
python tests/test_auth_function.py
python tests/test_afisha_filters_new.py
python tests/test_afisha.py
python tests/test_structure.py
node tests/run.js
```

Если `--check` выдаёт ошибку несовпадения исходника, **не запускайте `--apply`**. Это означает, что после нашего коммита файл изменился. Покажите сообщение ошибки для адаптации пакета. `--check` сам ничего не меняет.

Установщик сначала проверяет **все шесть файлов**, синтаксис Python и основных JS-блоков, и только затем меняет содержимое. Резервные копии шести старых файлов лежат в соседнем с проектом каталоге `OldPictureArt_backup_mobile_favorites_YYYYMMDD_HHMMSS`. При ошибке записи уже изменённые файлы восстанавливаются.

Изменяются только:

```text
site_common.py
sitebuild/afisha.py
sitebuild/posts.py
opa-ui.js
docs/opa-ui.js
docs/style.css
```

`afisha.json`, Telegram-сессии, изображения и `.env` **не изменяются**. GitHub-репозиторий **не изменяется** этим пакетом. Сборка обновит HTML-страницы из генераторов.

## Важные особенности

- Без входа избранное сохраняется в `localStorage` текущего браузера. После входа синхронизируется с облаком; для входа на афише предусмотрена отдельная кнопка.
- Если в одном браузере войти под **другим аккаунтом**, прежний список избранных выставок не переносится автоматически в чужой аккаунт.
- При недоступности облака новая отметка сохраняется локально, а синхронизация повторяется при следующей загрузке страницы или действии.
- Если выставку **полностью удалили из `afisha.json`**, она не будет отображаться в списке на сайте, даже если её ключ остался в YDB. Поэтому архивные записи лучше сохранять.
- Облачная синхронизация выставок использует **текущую** Yandex Cloud Function. Протестировать реальные учётные записи и состояние удалённой YDB из этой среды невозможно; тесты используют эмулятор API. Перед публикацией проверьте вход и сохранение избранного на двух настоящих устройствах.
- Если пользователь возвращается назад на страницу каталога, штатная прокрутка браузера сохраняется; исправлены только отступы и индикация фокуса.

## Проверка глазами на телефоне

Откройте главную, прокрутите список, зайдите в картину и вернитесь назад: панель сортировки не должна перекрывать записи, а рамки не должны прижиматься к тексту. Нажмите «Меню» — там должны быть поиск, счётчик и сортировка. Зайдите в афишу, нажмите ☆, убедитесь, что выставка видна в группе «Выставки» внутри избранного на главной. При входе и переходе на другой браузер отметка должна появиться после загрузки.
