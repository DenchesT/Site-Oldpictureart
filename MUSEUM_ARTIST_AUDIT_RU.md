## Применение ZIP

Архив содержит изменённые файлы с путями относительно корня проекта,
без внешней папки и без каталога Git. Перед распаковкой сохраните свои
незакоммиченные изменения. Распакуйте в `D:\Code\oldpictureart_site`.

Если устанавливаете ZIP, не применяйте затем повторно тот же набор изменений
из pull request. Для проверки: `python rebuild_pages.py --offline`,
затем `node tests/run.js`.
