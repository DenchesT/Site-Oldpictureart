# Old Picture Art — мобильная афиша и боковое меню (31 октября 2026)

Патч подготовлен для версии `DenchesT/Site-Oldpictureart` из GitHub, ветка `main`, коммит `06dc57c`.

## Что исправлено

- Мобильная афиша (до 700px): **шесть статусов** теперь отображаются отдельными прямоугольными кнопками, в **две колонки / три ряда**, с видимым зазором между ВСЕМИ кнопками. У каждой есть полная рамка, включая «Избранное» и «Все периоды».
- «На главную» и «Карта собраний» на телефоне больше не переносятся внутри словосочетаний; действия темы/аккаунта находятся рядом в компактном верхнем блоке.
- Уменьшены пустые вертикальные отступы шапки, фильтров и результата. Поле поиска и кнопка «Фильтры» одинаковой минимальной высоты 42px.
- Описание афиши **полностью сохранено**, включая фразу «Завершившиеся события сохраняются в архиве».
- Заголовок бокового меню главной **«Подборки» → «Избранное и популярное»**. Сами два раздела, избранные картины и выставки, работа авторизации и алгоритм популярного не меняются.
- Десктопный CSS не меняется — все новые правила ограничены `@media (max-width: 700px)`.

## Установка (PowerShell)

1. Скопируйте *три файла из архива* в `D:\Code\oldpictureart_site`:
   - `apply_mobile_afisha_fix.py`
   - `afisha_mobile_ui.css`
   - `test_mobile_afisha_fix.py`
2. Откройте PowerShell в корне сайта:

```powershell
python apply_mobile_afisha_fix.py --check
python test_mobile_afisha_fix.py
python apply_mobile_afisha_fix.py --apply
python rebuild_pages.py --offline
python tests/test_structure.py
python tests/test_afisha.py
node tests/test_afisha.js
```

**Важно:** В `tests/test_afisha.js` из предыдущего пакета уже была ошибка: тест выбирал скрытый фильтр открытия без смены вкладки «Скоро». Если этот файл ещё не обновлён, установите сначала исправление теста (`OldPictureArt_Afisha_UI_Test_Fix_2026-10-31.zip`) либо откройте «Скоро» перед проверкой открытия. Это не ошибка этого CSS-патча.

3. Проверьте `docs/afisha.html` в браузере на телефоне (лучше без кэша) и боковое меню `docs/index.html`.

Изменения будут видны на опубликованном сайте **только после коммита и отправки сгенерированных файлов в GitHub**. Этот ZIP сам ничего не публикует.

## Затронутые файлы

- `docs/style.css`: добавляется только мобильный блок стилей (помечен `OPA MOBILE AFISHA UI FIX 2026-10-31`).
- `sitebuild/posts.py`: заменяется заголовок «Подборки» на «Избранное и популярное».

Перед записью установщик создаёт резервные копии рядом с исходниками, с суффиксом `.before-mobile-afisha-<дата>.bak`. Второй запуск безопасен: дублирования CSS/HTML нет.

В файлах `sitebuild/afisha.py`, `afisha.json`, `.env`, пользовательских данных, изображениях и облачном избранном ничего не изменяется.
