# Old Picture Art — художественные музеи из Википедии, 31 октября 2026

## Содержимое

Этот пакет **не заменяет** существующий `afisha.json`. Он безопасно дополняет его справочником кандидатов на мониторинг из двух категорий Википедии и пятью выставками, информация о которых проверена на официальных музейных сайтах.

- `museum_seeds.txt` — снимок **113 прямых музейных статей**: 93 из «Художественные музеи России» и 20 музеев из «Художественные музеи»; списки и фонд из второй категории исключены.
- `verified_museums.json` — **18** источников с проверенными адресами и официальными сайтами. Адреса филиалов отличаются; см. комментарии.
- `museum_sources_prepared.json` — итоговый каталог **115 источников-кандидатов** (113 прямых страниц + два дополнительно проверенных музея: Третьяковская галерея и Русский музей).
- `museum_review_queue.csv` — таблица со статусами проверки **всех 115** кандидатов. Пустые адреса не означают, что адреса не существует: их ещё нужно проверить.
- `verified_exhibitions.json` — **5 проверенных временных выставок** с конкретными датами, адресами площадок и официальными ссылками. Не относятся к постоянным экспозициям.
- `import_wikipedia_museums.py` — установщик. Сохраняет существующие выставки, источники, фильтры, адреса и другие поля `afisha.json`.
- `test_wikipedia_museums.py` — локальные проверки объединения, повторного запуска, резервной копии и отсутствия дублей.

**Не утверждаем, что все сайты/адреса 115 учреждений уже проверены.** Две категории Википедии содержат вложенные категории, поэтому 113 статей — только прямые страницы сохранённого списка, а не полный рекурсивный каталог музеев мира.

## Установка (PowerShell, из корня Old Picture Art)

Распакуйте архив **прямо в корень проекта** `D:\Code\oldpictureart_site`. В ZIP нет вложенных папок. Все 8 файлов должны лежать рядом с `afisha.json`.

```powershell
cd D:\Code\oldpictureart_site
python import_wikipedia_museums.py --check
python test_wikipedia_museums.py
python import_wikipedia_museums.py --apply
python tests/test_afisha.py
python tests/test_structure.py
python rebuild_pages.py --offline
```

Все команды ниже рассчитаны на запуск из корня проекта.

`--check` показывает план **без записи**. `--apply` создаёт `afisha.json.pre_wikipedia_museums.bak` перед изменением и обновляет `afisha.json`. Повторный запуск не создаёт дублей. **Не передавайте `.env`, Telegram `.session` и другие секреты.**

**Очень важно:** справочник `sources` не равен перечню текущих выставок. Музеи без проверенной подходящей выставки будут источниками-кандидатами, **но не появятся в списке действующих выставок или фильтре музеев**, пока в `exhibitions` нет записи о выставке. Это предохраняет посетителей от пустых и ложных событий. Если у музея нет официального адреса сайта, в карточке источника он оставлен пустым, а не подменён Википедией.

## Полный обход вложенных категорий и сведения Wikidata

Для более широкого **онлайн** обнаружения музеев и предварительных адресов/сайтов выполните на компьютере с доступом в интернет:

```powershell
python import_wikipedia_museums.py --online --wikidata --check
python import_wikipedia_museums.py --online --wikidata --apply
```

Программа обращается к MediaWiki API и Wikidata API, проходит подкатегории на глубину до четырёх, максимум 1000 категорий. Если предел исчерпан, сообщает о неполном обходе. **Этот онлайн-режим здесь не был выполнен и отдельно в реальной сети не протестирован.** Сайты и адреса из Wikidata помечаются как *не проверено вручную*. Публиковать адреса / события как подтверждённые только по Wikidata не следует.

### Критерии отбора выставок

Только временные выставки со значимыми произведениями, созданными **до 1940 года**, с подтверждёнными датами и официальной ссылкой. Не добавлять концерты, экскурсии, постоянные экспозиции или преимущественно современное искусство. Сроки проверялись на 31 октября 2026 года.

| Выставка | Площадка | Даты |
| --- | --- | --- |
| Вечный Рим: гравюры династии Пиранези | Вятский художественный музей, Киров, Владимирская, 70 | 29.07.2026–31.01.2027 |
| Николай Хохряков. Поэзия природы | Дом-музей Хохрякова, Киров, Копанский пер., 4 | 29.05.2026–07.11.2026 |
| Окрестности Санкт-Петербурга в гравюрах и литографиях XIX века | Русский музей, Михайловский дворец, Инженерная, 4 | 05.08.2026–02.11.2026 |
| Личная история. Роберт Фальк и Андрей Юмашев | Ярославский художественный музей, Волжская наб., 23 | 25.09.2026–17.01.2027 |
| Ярославский культурный код | Ярославский художественный музей, Волжская наб., 1 | 21.03.2026–07.02.2027 |

У «Ярославского культурного кода» посещение **только организованными группами по предварительным заявкам**. На «Личной истории» заметная часть работ Юмашева относится к 1950–1960-м, но в экспозиции также есть произведения Фалька 1920–1940 годов; эта оговорка указана в `note`.

## Подходящие записи, уже имевшиеся в афише

На исходной версии проекта уже были «Выбор коллекционеров» Третьяковской галереи, «Илья Репин» Ярославского художественного музея и «Арзамасская академия» Нижегородского художественного музея. Их повторное добавление не требуется. Установщик проверяет дубли по названию и городу и не заменяет существующие записи.

## Проверка после объединения

Проверьте отчёт `--check`, затем запустите `python tests/test_afisha.py`, `python rebuild_pages.py --offline`. Проверьте даты и ссылки на опубликованном сайте. Файлы на GitHub данным архивом не изменяются автоматически. Для автоматического регулярного мониторинга 100+ сайтов понадобится отдельный обходчик — добавление `sources` само по себе **не создаёт** регулярный обход.
