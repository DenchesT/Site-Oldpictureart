# Old Picture Art — исправление Playwright-теста афиши

**Проблема:** `node tests/test_afisha.js` завершается `page.selectOption: Timeout 30000ms exceeded`, потому что `#afisha-opening` скрыт, пока активен статус «Идут». Это ошибка порядка действий в тесте из пакета `OldPictureArt_Afisha_UI_8_2026-10-31.zip`, а не причина для удаления поля или отключения проверок.

**Исправление:** тест явно выбирает вкладку «Скоро» перед проверкой открытия в ближайшие 90 дней. Проверка реальной фильтрации остаётся. Скрипт не меняет файлы сайта и данные, только `tests/test_afisha.js`.

## Установка (PowerShell)

Распакуйте содержимое ZIP в `D:\Code\oldpictureart_site`. Затем из корня проекта:

```powershell
python fix_afisha_ui_test.py --check
python test_fix_afisha_ui_test.py
python fix_afisha_ui_test.py --apply
node --check tests/test_afisha.js
node tests/test_afisha.js
```

Скрипт проверяет, что тест уже обновлён для интерфейса 31 октября, делает резервную копию и предотвращает повторную вставку. Если найдёт другую версию файла — остановится без изменений.

Если после этого тест остановится на другом шаге, пришлите полный лог: необходимо исследовать конкретную следующую ошибку, а не отключать проверки.

**Важно:** этот патч устраняет обнаруженный тайм-аут; он не означает, что все браузерные проверки прошли на вашем компьютере. GitHub и код генератора афиши не изменяются.
