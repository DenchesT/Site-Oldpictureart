# Old Picture Art — исправления публикации и адресов музеев

Подготовлено 30 октября 2026 года для `DenchesT/Site-Oldpictureart`, ветка `main`.
Это **патч исходников**, не копия сайта целиком. Он не отправляет файлы в GitHub самостоятельно.

## 1. Почему падала сборка

В приложенном логе генерация страниц завершилась. При публикации Git ответил:

```
! [rejected] main -> main (non-fast-forward)
```

Это значит, что в удалённой ветке появились коммиты, которых нет в локальной.
Программа успела создать локальный коммит с 446 изменёнными файлами, но не смогла отправить его. Это не ошибка карт и не проблема Telegram.

**Исправление:** в `sitebuild/safety.py` добавлена одна безопасная попытка: `git fetch origin main` → `git rebase origin/main` → `git push`, и только при *non-fast-forward*. Форсированный push не используется. Если возникает конфликт, программа выполняет `git rebase --abort` и пишет понятную ошибку с инструкцией; локальный коммит остаётся сохранённым. При проблемах авторизации или сети повторная синхронизация не выполняется.

Перед следующим запуском можно отдельно проверить `git status` и `git log -2 --oneline`.

## 2. Адреса и координаты

В исходном `museum_overrides.json` у большинства мест карты уже есть уличный адрес, а шесть частных собраний намеренно без публичных меток. Не следует придумывать для них адреса.

Пакет:

- Уточняет **16 отдельных выставочных площадок** по адресам, подтверждённым официальными сайтами музеев и культурными порталами. Совпадения выбираются строго по *названию + городу*.
- В текущем `afisha.json` у этих площадок **20 выставок**. У каждой задаются `address` и `query`: новая точная подсказка заставит геокодер пересмотреть приблизительный кэш на следующей **онлайн-сборке**.
- У ещё **58 выставок** есть ссылка на музей основного справочника (`museum`); адрес автоматически подставляется из уже существующего `museum_overrides.json`, без переопределения координат.
- Из-за одного пересечения получается ориентировочно **77 выставок с уличным адресом из 186**. У остальных уличный адрес не выдумывается: полный поимённый список остаётся в отчёте.
- Дополняет два старых алиаса Ростовского и Новгородского музеев и адрес Лондонской национальной галереи.
- На странице `afisha.html` адрес показывается под названием площадки, в прежнем шрифте и цветовой палитре.
- Меняет сообщение про «Русский Париж» с неоткрывающейся ссылки на доступную **официальную новость** организатора; дата и название остаются прежними.
- Создаёт `output/museum_address_audit.json`: перечень *всех* записей справочника, приблизительных координат в `afisha_places.json` и выставок без уличного адреса. Каталог `output` не участвует в автоматической публикации.

**Важно:** все записи сверены между исходными JSON по наличию адресов и координат. Внешняя пообъектная сверка **всех 69 музеев карты и всех 167 уникальных площадок афиши** с первоисточниками не завершена. Верифицированные по официальным источникам адреса перечислены ниже. ## 3. Установка на Windows

1. Сохраните резервную копию каталога проекта и проверьте состояние Git командой `git status`.
2. Распакуйте ZIP в **корень** `D:\Code\oldpictureart_site` (рядом с `build_site.py`).
3. Запустите в PowerShell:

```powershell
cd D:\Code\oldpictureart_site
python apply_verified_fixes.py --check
python apply_verified_fixes.py --apply
python test_verified_fixes.py
python -m compileall -q sitebuild
python tests/test_safety.py
python tests/test_afisha.py
python rebuild_pages.py --no-geocode
```

Установщик не трогает `.git`; он сохраняет отдельные резервные копии в `output/backups/` с суффиксами `.bak_ГГГГММДД_...` (они не попадают в Git). Его можно повторять: уже применённые изменения не создают новых патчей. Если текущий код отличается от ожидаемого, он **останавливается без частичной установки**.

Далее, когда есть доступ к интернету, нужен `python build_site.py`, чтобы геокодер обновил старые приблизительные координаты, а сайт перепубликовал HTML. **Внимание:** `build_site.py` делает автоматический `git commit` и `git push`.

Если после сборки случился конфликт на `rebase`, **не применяйте `git push --force`**. Посмотрите `git status`, затем разрешите конфликт вручную и отправьте изменения обычным `git push`.

## 4. Что осталось

- `Failed to load SSL library` / `cryptg module not installed`: предупреждение Telethon об ускорении шифрования; соединение с Telegram у вас установилось. Можно пользоваться Python 3.12 для проверенной совместимости.
- `proxy argument ignored because python-socks is not installed`: в логе FakeTLS-соединение успешно установлено. Это не причина отказа публикации.
- Для части выставок, не связанных с основным музейным справочником, уличных адресов пока нет. Они перечислены в `output/museum_address_audit.json`. Адреса нельзя безопасно угадать по названию города.
- Если геокодер не сумел точно найти место даже по адресу, точные координаты следует подтвердить по карте и явно добавить `lat`/`lon` в конкретную запись; ставить `approx = false` для координат центра города **нельзя**.
