# Исправление скачка прокрутки при добавлении выставки в избранное

Версия: 1 ноября 2026. Архив без вложенных папок. Файлы положить в корень `D:\Code\oldpictureart_site`.

## Причина

При отметке звёздочки в `sitebuild/afisha.py` срабатывает обработчик `opa:afisha-favorites`. Он вызывал `show()`, которая для любого лайка заново сортировала и переставляла все элементы `.afisha-item` в DOM. Это может сбрасывать прокрутку и на телефоне, и на компьютере.

## Что исправлено

- В обычном режиме выставок звёздочка и счётчик избранного обновляются **без перестановки элементов каталога**.
- В режиме «Избранное», где фильтрация действительно должна измениться, список обновляется без ненужной сортировки и с сохранением позиции прокрутки, насколько позволяет высота страницы.
- Не меняются сохранение в браузере / аккаунте, карта, поиск, сортировка, даты, стили или данные афиши.
- Изменяется только исходный генератор `sitebuild/afisha.py`.

## Установка

```powershell
python fix_afisha_favorite_scroll.py --check
python fix_afisha_favorite_scroll.py --apply
python test_afisha_favorite_scroll.py
python rebuild_pages.py --offline
node test_afisha_favorite_scroll.js
node tests/test_afisha.js
```

Если Playwright не установлен, поставьте зависимости командой `npm ci` (как для других тестов сайта). Для Chromium при необходимости используйте переменную окружения `CHROME_PATH`.

После установки обновите страницу в браузере без кэша и проверьте отметку выставки на компьютере и телефоне. Сайт не отправляется на GitHub автоматически.

Установщик при применении создаёт файл `sitebuild/afisha.py.before_favorite_scroll.bak`. Если точки изменения не совпадают с исходниками, установка останавливается, не перезаписывая файлы.
