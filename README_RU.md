# Old Picture Art — аккуратная доработка главной (12 пунктов)

Основа: `DenchesT/Site-Oldpictureart`, ветка `main`, коммит `2d209a10118773d71953f91beeadc1d98120c79e` (30 октября 2026). Это **пакет установки исходников**, а не полный архив изображений и HTML сайта.

## Какие изменения вносит пакет

1. **Компактная шапка:** меньше вертикальных отступов и более компактная типографика без изменения цветовой схемы и текста.
2. **Нет двойной крупной афиши:** «Мои посещения · текущие выставки» сворачиваются в одну строку с возможностью раскрытия; афиша в боковой панели остаётся. При отсутствии действующих выставок эта строка скрывается автоматически. Внутренние даты и ссылки не удаляются.
3. **Одна прокрутка на компьютере:** у боковой панели убрана независимая вертикальная прокрутка, поиск остаётся закреплённым в пределах панели. На телефоне выдвижная панель по-прежнему прокручивается независимо — иначе до нижних пунктов было бы не добраться.
4. **Ясные группы в боковой панели:** фильтры картин / выставки и подборки / разделы сайта, тема в конце.
5. **Миниатюры больше на 15–20%:** увеличены размеры изображений в подробном списке, исходные пропорции сохранены. Для разных экранов предусмотрены адаптивные размеры.
6. **Понятные названия сортировки:** «Недавно добавленные», «По году картины: ранние / поздние» и общая надпись «Сортировка».
7. **Удобное открытие картины:** кроме уже работающей ссылки на изображении и растянутой ссылки карточки, название картины становится самостоятельной доступной ссылкой; более заметно наведение и фокус с клавиатуры. Ссылка на музей остаётся независимой.
8. **Читаемые характеристики справа:** увеличен размер текста и контраст подписей, цифры выровнены.
9. **Счётчик найденных работ:** всегда виден «Найдено N картин», при выборе фильтров рядом появляется «Сбросить фильтры».
10. **Закреплённые сортировка и виды:** панель над списком остаётся доступной при прокрутке, на телефоне учитывает кнопку меню.
11. **Понятный поиск:** видимый заголовок «Поиск картин», подсказка о горячей клавише `/`, кнопка очистки; фильтры и чипы синхронизируются после очистки.
12. **Номер картины:** появляется «№ 037» и подсказка «Номер работы в каталоге». Исходный числовой текст номера остаётся неизменным для существующих тестов.

**Дополнительно:** удалены три неиспользуемых импорта, из-за которых `tests/test_structure.py` падает в GitHub Actions (в `apply_ui_12.py`, `test_installer.py`, `sitebuild/visits.py`).

## Какие файлы изменятся при применении

- `sitebuild/posts.py` — **генератор главной** (HTML и существующий JS фильтров).
- `docs/style.css` — только дополнительные CSS-правила, ограниченные главной страницей.
- `opa-ui.js` — синхронизация ярлыков фильтров и скрытие пустого блока посещений.
- `apply_ui_12.py`, `test_installer.py`, `sitebuild/visits.py` — только удаление неиспользуемых импортов.

Никаких правок `afisha.json`, `visits_meta.json`, `posts_meta.json`, `.env`, Telegram-сессий, изображений, `docs` HTML-страниц вручную, конфигурации Git или GitHub.

## Как установить на Windows

Распакуйте ZIP прямо в корень `D:\Code\oldpictureart_site` с сохранением файлов и вложенной папки `fixtures`. В PowerShell:

```powershell
cd D:\Code\oldpictureart_site
python apply_home_polish.py --check
python test_home_polish.py
python apply_home_polish.py --apply
python -m compileall -q sitebuild
python rebuild_pages.py --offline
python tests/test_structure.py
node tests/run.js
```

**ВАЖНО:** `--check` ничего не меняет. `--apply` исправляет исходные генераторы, а не только опубликованный HTML. Перед записью создаются копии `*.before-home-polish.bak` (игнорируются Git), все исправления планируются заранее; при отказе записи уже изменённые файлы восстанавливаются. Повторный `--apply` безвреден.

После успешной **локальной** проверки можно сделать коммит и отправить изменения, если это действительно нужно. Скрипт не вызывает `git` и ничего не публикует самостоятельно. Наличие пользовательских изменений лучше сначала проверить `git status`, не делать `git reset --hard`.

Если `--check` скажет, что исходник отличается от ожидаемого, **не применяйте вручную**: отправьте текст ошибки и текущий `sitebuild/posts.py`. В этом случае никаких изменений ещё не внесено.
