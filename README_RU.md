# Old Picture Art — афиша и главное меню (31 октября 2026)

Пакет составлен по `DenchesT/Site-Oldpictureart`, ветке `main` на 31.10.2026 (проверены ревизии `d287a40f` и `4da406e3`). Учитывает установленное ранее обновление мобильного интерфейса и облачного избранного выставок. **Не меняет** `afisha.json`, `museum_overrides.json`, `.env`, Telegram-сессии, изображения или конфигурацию авторизации. Сами данные выставок остаются в прежнем виде. Дизайн, цветовая палитра, шрифты сохранены.

## Что сделано

**Афиша — все восемь выбранных улучшений:**

1. Компактный заголовок и описание, меньше пустоты над афишей.
2. Сначала география и статусы: «Сейчас и скоро», «Идут», «Скоро», «Архив», «★ Избранное», «Все периоды». Статус больше не спрятан под фильтрами.
3. Соответствующие датам фильтры появляются в зависимости от статуса. Для архива — выбор года.
4. Один поиск по выставке, художнику, музею и городу вместо двух полей; фильтрация по мере ввода сохранена.
5. Поля города, музея и эпохи выровнены, дополнительные настройки собраны под раскрывающимся заголовком; на узком экране остаются поиск, статусы и кнопка «Фильтры».
6. «★ Избранное» — отдельная вкладка с количеством отмеченных выставок (включая завершившиеся). Использует имеющийся механизм сохранения в браузере/облаке из предыдущего пакета, новую БД не создаёт. Кнопки-звёздочки сохранены.
7. В «Успеть на этой неделе» сначала три выставки, остальные раскрываются кнопкой.
8. Над результатами — число найденных выставок, выбранные условия с возможностью снять каждое отдельно, общий сброс и сортировка.

**Главная страница:** в левой панели под заголовком «Разделы сайта» теперь единственная ссылка **«Выставки»**. Список анонсов из сайдбара удалён; верхний разворачиваемый блок «Мои посещения · текущие выставки» также удалён. При этом отдельная страница **«Посещения»** не меняется.

**Телефон:** сортировка, переключатель «Подробный список / Карточки» и счётчик возвращены **над галереей**, а не внутрь бокового «Меню». Панель больше не закрепляется поверх картин. Исправления отступов на мобильных карточках из прошлого пакета сохранены.

## Установка в PowerShell

1. Перед изменениями сохраните незакоммиченные файлы или сделайте резервную копию репозитория. Пакет сам создаёт папку `_backup_afisha_ui_...` с копиями изменяемых файлов.
2. Распакуйте файлы из ZIP в корень `D:\Code\oldpictureart_site` (пакет содержит только установщик, тест и эту инструкцию; в ZIP не требуется создавать вложенную папку).
3. Из папки проекта выполните:

```powershell
cd D:\Code\oldpictureart_site
python apply_afisha_ui.py --check
python apply_afisha_ui.py --apply
python rebuild_pages.py --offline
python test_afisha_ui.py
python tests/test_afisha.py
python tests/test_afisha_filters_new.py
python tests/test_structure.py
node tests/test_afisha.js
node tests/test_ui.js
```

Для браузерных тестов требуется установленный `node_modules` с Playwright и браузер (смотрите README проекта). Сборка `--offline` не обращается к Telegram или геокодеру.

**Публикация:** установщик не делает `git commit`/`git push`. Если локальные тесты прошли, проверьте `git status` и `git diff` и отправьте изменения своим обычным способом. Не отправляйте `.env`, `*.session`, `_backup_afisha_ui_*`.

## Совместимость

`--check` сверяет ключевые участки текущих генераторов с известной версией и проверяет синтаксис Python/JavaScript. Если какой-то участок изменился, остановится **до записи** любых файлов. В таком случае **не пытайтесь заменять его текстом вручную**: пришлите текст ошибки, нужно будет согласовать изменения с вашей локальной версией.

Установщик идемпотентный: после применения повторная команда `--check` не дублирует вставки.

## Проверки при подготовке

- Синтаксис Python-установщика и сгенерированного изменённого `afisha.py` проверен.
- `node --check` прошёл для изменённого основного скрипта афиши.
- На модельной HTML-странице в Chromium проверены состояния «Идут», «Архив», «Избранное», подсчёт выставок, живой поиск и раскрытие срочных выставок.
- Проверены точные строки изменяемых участков текущей версии GitHub и синтаксис точечных правок тестов на синтетических примерах.

**Не утверждается**, что полный набор тестов конкретно вашей локальной копии сайта уже прошёл. Для окончательной проверки нужны команды выше после применения в вашей папке.
