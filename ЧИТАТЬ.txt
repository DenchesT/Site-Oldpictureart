Страница музеев: выбор карты и новая раскладка
==============================================

Распакуйте поверх папки репозитория с заменой файлов.

В корень проекта (1):
    generate_map.py

В папку docs (2):
    docs/map-config.js
    docs/style.css

ПОСЛЕ ЗАМЕНЫ:

    python rebuild_pages.py

КЛЮЧ ЯНДЕКС.КАРТ (по желанию)
Откройте docs/map-config.js и впишите ключ между кавычками.
Где взять: https://developer.tech.yandex.ru — тариф
«JavaScript API и HTTP Геокодер», бесплатный лимит есть.
Ключ обязательно ограничьте доменом denchest.github.io:
на статическом сайте он виден всем в исходниках страницы.
Без ключа слой Яндекса просто не появится в переключателе,
остальные четыре карты работают без всякой регистрации.

ВНИМАНИЕ: файл docs/map-config.js сборка не перезаписывает,
вписанный ключ переживёт пересборку сайта.
