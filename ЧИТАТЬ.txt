Правки по списку
================

Распакуйте поверх папки репозитория с заменой файлов.

    build_site.py
    docs/style.css
    generate_map.py
    generate_timeline.py
    museum_overrides.json
    site_common.py

ПОСЛЕ ЗАМЕНЫ:

    python rebuild_pages.py

ЧТО ИЗМЕНИЛОСЬ
  1. «Основа» → «Материал», значение со строчной буквы
  2. Таймлайн: внутри десятилетия работы по возрастанию года
  3. Кнопка «наверх»: убрана на телефонах, на компьютере
     компактная, с кольцом прогресса по странице
  4. Раздел «Годы» в фильтрах: столбики по десятилетиям + от/до.
     Плюс выбор порядка записей над списком
  5. Музеи кликабельны: ведут на карту с подсветкой. В карточке
     музея — ссылка на официальный сайт

ДОБАВИТЬ САЙТ МУЗЕЯ
  museum_overrides.json, поле site у нужного музея:
    "Музей Фабра, Монпелье": {"query": "...", "site": "https://..."}
