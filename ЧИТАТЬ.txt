Карта музеев: кэш координат
===========================

Распакуйте поверх папки репозитория с заменой файлов.

    README.md
    generate_map.py
    rebuild_pages.py

ПОСЛЕ ЗАМЕНЫ:

    python rebuild_pages.py

Теперь координаты берутся из museum_coordinates.json и в сеть
скрипт не ходит. Перепоиск случается только если:
  - появился новый музей, которого нет в кэше
  - вы поменяли подсказку в museum_overrides.json
  - запуск был с --regeocode

ОДИН РАЗ нужно выполнить с интернетом:

    python generate_map.py --regeocode

Это займёт пару минут и расставит недостающие 34 музея.
Дальше всё будет мгновенно.

Ещё есть --no-geocode: собрать карту только по готовым
координатам, не обращаясь в сеть даже за новыми музеями.
